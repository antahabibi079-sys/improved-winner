Live Chat

आपके लाइव स्ट्रीम के लिए रियल-टाइम चैट

1. Firebase सेटिंग

अपनी Firebase Web App की config नीचे डालें। ये सार्वजनिक client config है; सुरक्षा Firebase Rules और Authentication से आती है। कोई Admin SDK secret यहाँ न डालें।

अभी Firebase कनेक्ट नहीं है।

नोट: Firebase Console में Authentication → Email/Password चालू करें और Realtime Database बनाएं। नीचे दिए गए README में चरण और सुरक्षा Rules हैं।

2. Login / Register

Login करने के बाद चैट में जुड़ें।

3. Live Room

हर लाइव के लिए एक room ID रखें। दर्शकों को यही ID दें, उदाहरण: live123.

अभी किसी room में नहीं जुड़े हैं।

4. Live Chat

Firebase कनेक्ट करें, Login करें और room में जुड़ें।
दर्शकों के लिए: वेबसाइट लिंक में ?room=live123 जोड़कर room पहले से चुना जा सकता है। सभी संदेश सार्वजनिक room में दिखेंगे; निजी जानकारी न भेजें।

Starter version: यह चैट और Firebase login का हिस्सा है, पूरी streaming service नहीं। वीडियो चलाने के लिए अलग LiveKit/media-server integration चाहिए।
